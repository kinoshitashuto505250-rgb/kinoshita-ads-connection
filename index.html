KINOSHITA / AD DATA

広告実績を記録し、
日々の判断につなげる。

木下集客支援事業所の担当業務で利用する「広告実績連携ツール」です。アクセスを許可されたGoogle広告のうち、担当案件として設定したアカウントの実績を取得し、日々の確認や報告に利用します。

Google認証設定のアプリ名：木下集客支援事業所 広告実績連携ツール

何のために使うか

01 / COLLECT

広告実績を取得

広告費、表示回数、クリック数、コンバージョンなどを、アカウント・キャンペーン・日付ごとに取得します。

02 / KEEP

記録を蓄積

取得したデータと取得日時・成否を保存します。未取得や認証エラーを、実績ゼロとして扱わないよう区別します。

03 / REVIEW

確認・分析に利用

指定された保管庫やローカルの記録から、担当案件の経緯と数字を参照し、分析や報告作成に役立てます。

利用者と取得対象

このツールは木下集客支援事業所の担当者自身の業務利用向けです。不特定多数向けのサービスや、他社の公式アプリとして提供するものではありません。

Googleへの接続には、利用者自身の同意と、対象アカウントへの既存のアクセス権を使用します。アクセス可能な全広告アカウントを一律に取得するのではなく、担当案件として設定された対象を取得します。

定期取得プログラムは読み取り用途です。広告の予算・入札・配信状態・広告内容を自動変更する機能は、この定期取得処理に含めません。

Google広告のAPI権限自体には編集等が含まれますが、権限が存在することと、変更を実行することは別です。また、同じGoogle CloudプロジェクトにはGoogleタグマネージャーの編集権限も登録されています。広告実績の定期取得処理では使用しません。

データの流れ

Google広告 API → ローカルの記録 → 指定の保管庫・分析

取得データは利用者のPC上のデータベースやファイルに保存し、指定したObsidian保管庫等の表示に反映します。保存先の設定により、クラウドストレージに同期される場合があります。

利用者が指定するAIサービスで検索・分析・報告作成に利用する場合があります。この説明サイト自体に、広告データの表示・アップロード・Googleへのログイン機能はありません。
